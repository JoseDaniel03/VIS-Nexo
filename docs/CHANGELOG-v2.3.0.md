# v2.3.0 — Proyectos, publicaciones y recursos

- Hero de proyecto full-bleed y degradado vertical integrado con el fondo.
- Publicar noticias, parches, updates y eventos directamente desde la página (solo admin).
- Editar/eliminar publicaciones en cada pestaña sin abrir administración general.
- Crop/zoom/drag de banner, logo e icono; copia PNG importada con comando Rust `save_cropped_asset`.
- Corrige la pérdida silenciosa del banner al recorrer los pasos del asistente (se excluyen botones del guardado de campos).
- Mensajes sobre publicación local y permisos; el original permanece intacto.
- Mismo backend de cuentas, instancia y catálogo que la 2.2.
